# Comentarios do prof para o projeto geral:

1. Analisar os PDFs no formato atual e gerar as planilhas, de forma a remover esse gargalo da ARPE;
2. Analisar os PDFs no formato otimizado (já entregue à CEASA), de forma ter uma precisão maior das próximas entregas;
3. Desenvolver um sistema de gerenciamento (parcial) das entregas, onde o fornecedor (CEASA ou qualquer outro) preenche as informações, o sistema gera a guia (PDF), depois fazem a impressão, coletam a assinatura no momento da entrega e, por fim, anexam o scan do PDF no sistema.

Portanto, vamos ter que mesclar a parte de desenvolvimento web, com a extração de caracteres do PDF, pra conferir se o que foi emitido pelo sistema foi o mesmo anexado depois.

Essa solução é boa por um lado, pois simplifica o nosso trabalho e garante uma durabilidade muito maior do sistema, pois o formato de saída e entrada já será conhecido por pelo sistema.
